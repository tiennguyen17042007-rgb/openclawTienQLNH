# 🛒 Online Shopping System

## 1. Giới thiệu dự án

Dự án xây dựng website bán hàng trực tuyến đơn giản, giúp người dùng xem sản phẩm, tìm kiếm, lọc sản phẩm và thêm sản phẩm vào giỏ hàng.

Dự án được thực hiện nhằm thực hành HTML, CSS và JavaScript.

## 2. Chức năng chính

- Hiển thị danh sách sản phẩm.
- Tìm kiếm sản phẩm.
- Lọc sản phẩm.
- Thêm sản phẩm vào giỏ hàng.
- Cập nhật số lượng sản phẩm.
- Tính tổng tiền đơn hàng.
- Mô phỏng quá trình đặt hàng.

## 3. Công nghệ sử dụng

- **HTML:** Xây dựng cấu trúc website.
- **CSS:** Thiết kế giao diện.
- **JavaScript:** Xử lý các chức năng.
- **JSON:** Lưu dữ liệu sản phẩm mẫu.

## 4. Cấu trúc dự án

```text
online-shopping-system/
├── index.html
├── style.css
├── app.js
├── data.json
└── README.md
```

*Lưu ý: Cấu trúc trên là ví dụ, cần điều chỉnh theo các file thực tế trong dự án.*

## 5. Hướng dẫn chạy dự án trên máy tính

### Bước 1: Tải mã nguồn

Truy cập repository GitHub:

[GitHub - Online Shopping System](https://github.com/tiennguyen17042007-rgb/openclawTienQLNH/tree/main)

Nhấn **Code → Download ZIP**, sau đó giải nén vào máy tính.

### Bước 2: Mở dự án

1. Mở Visual Studio Code.
2. Chọn **File → Open Folder**.
3. Chọn thư mục dự án vừa giải nén.

### Bước 3: Cài đặt Live Server

1. Chọn **Extensions** trong VS Code.
2. Tìm `Live Server`.
3. Nhấn **Install**.

### Bước 4: Chạy website

1. Mở file `index.html`.
2. Nhấn chuột phải vào file.
3. Chọn **Open with Live Server**.
4. Trình duyệt sẽ tự động mở website.

**Lưu ý:** Nếu dự án sử dụng `fetch()` để đọc dữ liệu từ file JSON, nên chạy bằng Live Server thay vì mở trực tiếp file HTML.

## 6. 🚀 Chạy Demo Dự Án Trực Tuyến

👉 **[Bấm vào đây để chạy Demo Website](https://tiennguyen17042007-rgb.github.io/openclawTienQLNH/index.html)**

Người dùng có thể mở đường dẫn demo để trải nghiệm website trực tiếp trên trình duyệt mà không cần mở VS Code.

**Nếu link chưa hoạt động:**

1. Truy cập [repository GitHub](https://github.com/tiennguyen17042007-rgb/openclawTienQLNH).
2. Chọn **Settings → Pages**.
3. Tại mục **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn nhánh `main` và thư mục `/(root)`.
5. Nhấn **Save**.
6. Chờ GitHub Pages triển khai website rồi thử lại đường dẫn demo.

*Lưu ý: Link demo ở trên là đường dẫn dự kiến, chưa được xác nhận hoạt động. Repository cần có file `index.html` ở vị trí phù hợp và GitHub Pages phải được bật thành công.*

## 7. Cách sử dụng website

Sau khi mở website, người dùng có thể:

1. Xem danh sách sản phẩm.
2. Tìm kiếm sản phẩm theo tên.
3. Lọc sản phẩm theo các tiêu chí được hỗ trợ.
4. Thêm sản phẩm vào giỏ hàng.
5. Thay đổi số lượng sản phẩm.
6. Kiểm tra tổng tiền.
7. Thử chức năng đặt hàng nếu đã được triển khai.

## 8. Hạn chế của dự án

- Dữ liệu sản phẩm có thể chỉ là dữ liệu mẫu.
- Đơn hàng có thể chưa được lưu vào cơ sở dữ liệu.
- Chưa có đăng nhập và thanh toán thực tế nếu chưa được triển khai.
- Các chức năng thực tế phụ thuộc vào mã nguồn hiện có.

## 9. Hướng phát triển

- Xây dựng backend và cơ sở dữ liệu.
- Bổ sung chức năng đăng ký, đăng nhập.
- Hoàn thiện quản lý đơn hàng.
- Tích hợp thanh toán trực tuyến.
- Nghiên cứu tích hợp AI hoặc OpenClaw để hỗ trợ tự động hóa.
